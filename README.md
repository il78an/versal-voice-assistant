# Versal Voice Assistant

Android-приложение на Kotlin для голосового управления Яндекс Музыкой. Целевое устройство первого тестирования — **Honor X8C / MagicOS**. Язык команд — русский. Целевая ключевая фраза фонового режима — **«Помощник»**.

## Текущее состояние

Это стартовая сборка репозитория. Сейчас доступны ручное распознавание команды и экранный непрерывный режим через системный Android SpeechRecognizer. Медиакоманды отправляются через Android AudioManager.

**Фоновое пробуждение по слову «Помощник» пока не реализовано.** Экранный непрерывный режим — не фоновый wake-word detector. Системный SpeechRecognizer может обращаться к сетевому сервису и не является локальным низкопотребляющим детектором ключевой фразы.

## Команды

- Открой / закрой Яндекс Музыку.
- Включи / останови музыку.
- Следующий / предыдущий трек.
- Громкость плюс / минус пять или десять.

«Закрыть Яндекс Музыку» ставит воспроизведение на паузу и возвращает пользователя на домашний экран: Android не разрешает обычному приложению принудительно завершать другое приложение. Изменение громкости приблизительное, поскольку системная шкала дискретная.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.9. В Android Studio откройте корень репозитория и выполните Gradle Sync. Команда сборки: `gradle assembleDebug`.

GitHub Actions собирает debug APK при push в `main`, pull request в `main` и по ручному запуску. APK публикуется в артефактах workflow под именем `versal-voice-debug-apk`.

## План реализации фонового режима

1. Foreground service типа `microphone`, постоянное уведомление и запуск пользователем из видимого Activity.
2. Локальный wake-word detector с проверенной русской моделью для фразы «Помощник».
3. После срабатывания — распознавание команды, выполнение, голосовой ответ через Android TTS и возврат в ожидание.
4. Испытания на Honor X8C с заблокированным экраном и инструкции по настройкам фоновой активности MagicOS.

## Ограничения платформы

- Android 14+ ограничивает запуск микрофонной foreground-службы из фона. Её следует запускать из открытого приложения.
- Настройки энергосбережения производителя могут остановить даже foreground service.
- Управление воспроизведением зависит от активной медиасессии Яндекс Музыки.
- Идентификатор пакета Яндекс Музыки `ru.yandex.music` нужно подтвердить на конкретном устройстве.

## Статус проверки

Исходники загружены в репозиторий; успешная сборка GitHub Actions и работа на физическом Honor X8C пока не подтверждены.
