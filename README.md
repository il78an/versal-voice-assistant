# Версаль — голосовой помощник

Android-приложение на Kotlin для голосового управления Яндекс Музыкой и YouTube, включая Shorts. Целевое устройство первого тестирования — **Honor X8C / MagicOS**. Язык команд — русский. Ключевая фраза фонового режима — **«Помощник»**.

## Распознавание речи

- Vosk распознаёт ключевую фразу «Помощник».
- Sherpa-ONNX распознаёт голосовые команды офлайн.
- Если Sherpa-ONNX не удалось инициализировать, остаётся резервный путь распознавания через Vosk.
- Модели загружаются при первом запуске и хранятся локально.

## Яндекс Музыка

- Открой / закрой Яндекс Музыку.
- Включи / останови музыку.
- Следующий / предыдущий трек.
- Установка громкости в процентах, например «громкость 30».

Закрытие приложения ставит воспроизведение на паузу и возвращает пользователя на главный экран: Android не разрешает обычному приложению принудительно завершать другое приложение.

## YouTube и Shorts

Когда YouTube находится на переднем плане:

- «Пауза», «останови видео» — остановить воспроизведение.
- «Продолжи видео», «играй» — продолжить воспроизведение.
- «Следующее видео», «дальше» — свайп вверх к следующему Short.
- «Предыдущее видео», «назад» — свайп вниз.
- «Громкость 30» — установить громкость.
- «Закрой YouTube» — поставить видео на паузу и вернуться на главный экран.

Также можно открыть YouTube командой «Помощник, открой YouTube».

Для перелистывания Shorts и возврата на главный экран должна быть включена служба «Версаль» в настройках специальных возможностей Android. Жесты отправляются только когда служба определяет YouTube как приложение на переднем плане.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.9. В Android Studio откройте корень репозитория и выполните Gradle Sync. Команда сборки: `gradle assembleDebug`.

GitHub Actions собирает debug APK при push в `main`, pull request в `main` и по ручному запуску. APK публикуется в артефактах workflow под именем `versal-voice-debug-apk`.

## Ограничения Android

- Фоновую микрофонную службу следует запускать из открытого приложения.
- Энергосбережение MagicOS может влиять на работу фоновой службы.
- Пауза и продолжение YouTube зависят от обработки медиаклавиш приложением.
- Перелистывание Shorts выполняется жестами специальных возможностей; поведение может зависеть от версии YouTube и расположения элементов интерфейса.
- Обычное приложение Android не может принудительно завершить другое приложение. Команда закрытия останавливает видео и возвращает пользователя на домашний экран.
